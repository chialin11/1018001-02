# 嘉琳攝影工作室：Google 試算表詢問單設定

完成設定後，訪客從網站送出詢問表單，資料會新增到 Google 試算表的「詢問單」工作表，並寄送通知到指定 Email。

## 一、建立 Google 試算表與 Apps Script
1. 到 Google 試算表建立一份新試算表，名稱可設為「嘉琳攝影工作室－網站詢問單」。
2. 在試算表選單點「擴充功能」→「Apps Script」。
3. 將編輯器內原本的程式刪除，完整貼上本資料夾的 `Code.gs` 內容。
4. 把 `NOTIFICATION_EMAIL` 改成你要接收新詢問通知的 Email，例如 `yourname@gmail.com`。請保留單引號。
5. 儲存專案。

## 二、部署成網頁應用程式
1. Apps Script 右上角點「部署」→「新增部署作業」。
2. 點齒輪/選取類型，選「網頁應用程式」。
3. 「執行身分」選「我」。
4. 「誰可以存取」選「所有人」（若你的 Google Workspace 管理員限制此選項，需改用可公開存取的帳號或部署方式）。
5. 點「部署」，依提示授權試算表與寄送電子郵件權限。
6. 複製部署完成後的「網頁應用程式 URL」，通常結尾是 `/exec`。

## 三、把 URL 貼進 index.html
在 `index.html` 找到：

```js
const GOOGLE_APPS_SCRIPT_URL = '請貼上你的Apps Script網頁應用程式URL';
```

把引號內文字換成剛才複製的 `/exec` URL。請勿把 URL 貼到 `Code.gs`。

## 四、部署到 GitHub / Vercel
將更新後的 `index.html` 與 `images` 資料夾一起推送到 GitHub。Vercel 會自動重新部署。`Code.gs` 是貼到 Google Apps Script 的程式，不需要放到網站根目錄才能運作。

## 五、測試
1. 打開已部署的網站，填一筆測試詢問單並送出。
2. 檢查試算表是否新增一列。
3. 檢查通知 Email 的收件匣及垃圾郵件匣。
4. 若修改了 Apps Script 程式碼，請到「部署」→「管理部署作業」編輯部署，選擇新版本後重新部署；若建立新的部署，記得更新 `index.html` 裡的 URL。

## 注意事項
- 網頁使用 `no-cors` 方式送出資料，瀏覽器無法讀取 Google Apps Script 回傳的實際結果。因此網站會顯示「已送出」提示，但這不等於後端一定成功；首次設定後務必實際測試試算表與 Email。
- 公開表單可能收到垃圾訊息；程式有簡易隱藏欄位檢查，但不是完整防濫用機制。
- 不要把私人試算表 ID、存取權杖或其他秘密資料放進前端。此方案的 Apps Script URL 會出現在網站程式中，請勿將表單設計成收集身分證、信用卡等敏感資料。
